# CaseLab

Web mô phỏng mở hòm CS2: mở hòm, nâng cấp, hợp đồng, kho đồ. Tiền ảo, không cần đăng nhập. Số dư và kho đồ lưu trong trình duyệt của người chơi.

## Chạy

- **GitHub Pages / hosting tĩnh:** chỉ cần `index.html` và thư mục `img/`.
- **Node.js:** `node server.js` (mặc định cổng 3000, đổi bằng biến `PORT`).

Trang mô phỏng giải trí, không liên kết với Valve hay bất kỳ trang mở hòm nào.
